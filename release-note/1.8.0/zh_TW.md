## [1.8.0]

### 新增
- 新增圖庫功能，支援新增照片來源，並依時間軸集中瀏覽照片與影片
- 新增智慧搜尋，支援透過自然語言、圖片中的文字及畫面內容尋找照片
- 新增地圖瀏覽，可依國家或地區、城市及地點查看照片
- 新增相簿、收藏與最近瀏覽，協助使用者更方便地整理及尋找重要照片
- 新增回憶功能，自動整理歷年今日、地點回憶及旅程故事
- 新增部分裝置的風扇控制策略，提升散熱效能與運作穩定性
- 新增 Spotlight 功能支援，可透過 Spotlight 快速搜尋及存取裝置中的相關功能與內容
- 新增支援部分 Intel 平台的觸控螢幕及 GPIO 設定
- 新增 AMD CPU 溫度顯示

### 修復
- 修復無法變更系統時區的問題
- 修復裝置資訊中顯示的記憶體頻率與實際頻率不一致的問題
- 修復建立 RAID 時，部分情境下視窗底部的「建立」按鈕可能被遮擋的問題
- 修復部分情境下備份工作占用過多系統資源的問題
- 修復部分情境下 RAID 修復操作未依預期執行的問題
- 修復 ACPI 處理不當導致 CPU 拓撲顯示異常的問題

### 優化
- 優化 Docker 應用程式生命週期管理，提升應用程式啟動、停止及狀態切換的可靠性
- 優化應用程式設定頁面的 CPU 資源上限邏輯，上限現在會根據裝置資訊中偵測到的 CPU 執行緒數自動決定
- 優化應用程式解除安裝流程，支援在解除安裝時選擇刪除或保留應用程式資料
- 優化 Btrfs 寫回抑制，減少 COW 放大並提升寫入效能
- 優化使用者驗證體驗；裝置重新啟動後，在大多數情境下無需再次輸入密碼
- 優化應用程式詳細資料頁面的記憶體資訊顯示
