## [1.8.0]

### New
- Προστέθηκε βιβλιοθήκη φωτογραφιών που υποστηρίζει την προσθήκη πηγών φωτογραφιών και την περιήγηση σε φωτογραφίες και βίντεο σε ενιαίο χρονολόγιο
- Προστέθηκε η Έξυπνη αναζήτηση, που επιτρέπει την εύρεση φωτογραφιών μέσω φυσικής γλώσσας, κειμένου σε εικόνες και οπτικού περιεχομένου
- Προστέθηκε περιήγηση σε χάρτη, ώστε οι χρήστες να βλέπουν φωτογραφίες ανά χώρα ή περιοχή, πόλη και τοποθεσία
- Προστέθηκαν άλμπουμ, αγαπημένα και στοιχεία που προβλήθηκαν πρόσφατα για ευκολότερη οργάνωση και εύρεση σημαντικών στοιχείων
- Προστέθηκαν οι Αναμνήσεις, που οργανώνουν αυτόματα στιγμιότυπα της ημέρας, αναμνήσεις τοποθεσίας και ταξιδιωτικές ιστορίες
- Προστέθηκαν στρατηγικές ελέγχου ανεμιστήρα για επιλεγμένες συσκευές, ώστε να βελτιωθούν η ψύξη και η σταθερότητα λειτουργίας
- Προστέθηκε υποστήριξη Spotlight, επιτρέποντας γρήγορη πρόσβαση σε σχετικές λειτουργίες και περιεχόμενο της συσκευής μέσω του Spotlight
- Προστέθηκε υποστήριξη διαμόρφωσης οθόνης αφής και GPIO για επιλεγμένες πλατφόρμες Intel
- Προστέθηκε εμφάνιση θερμοκρασίας CPU AMD

### Fixed
- Διορθώθηκε ένα ζήτημα που εμπόδιζε τους χρήστες να αλλάξουν τη ζώνη ώρας του συστήματος
- Διορθώθηκε ένα ζήτημα όπου η συχνότητα μνήμης που εμφανιζόταν στις πληροφορίες συσκευής δεν αντιστοιχούσε στην πραγματική συχνότητα
- Διορθώθηκε ένα ζήτημα όπου το κουμπί Δημιουργία στο κάτω μέρος του παραθύρου δημιουργίας RAID μπορούσε να καλυφθεί σε ορισμένα σενάρια
- Διορθώθηκε ένα ζήτημα όπου οι εργασίες αντιγράφων ασφαλείας κατανάλωναν υπερβολικούς πόρους συστήματος σε ορισμένα σενάρια
- Διορθώθηκε ένα ζήτημα όπου οι λειτουργίες επιδιόρθωσης RAID δεν εκτελούνταν όπως αναμενόταν σε ορισμένα σενάρια
- Διορθώθηκε η μη φυσιολογική εμφάνιση της τοπολογίας CPU που προκαλούνταν από ακατάλληλο χειρισμό ACPI

### Optimized
- Βελτιστοποιήθηκε η διαχείριση του κύκλου ζωής των εφαρμογών Docker για βελτίωση της αξιοπιστίας κατά την εκκίνηση, τον τερματισμό και τις μεταβάσεις κατάστασης
- Βελτιστοποιήθηκε η λογική ορίου πόρων CPU στη σελίδα διαμόρφωσης εφαρμογών. Η μέγιστη τιμή καθορίζεται πλέον με βάση τον αριθμό νημάτων CPU που εντοπίζονται στις πληροφορίες συσκευής
- Βελτιστοποιήθηκε η ροή απεγκατάστασης εφαρμογών, επιτρέποντας στους χρήστες να επιλέξουν αν θα διαγράψουν ή θα διατηρήσουν τα δεδομένα της εφαρμογής
- Βελτιστοποιήθηκε ο περιορισμός επανεγγραφής του Btrfs για τη μείωση της ενίσχυσης COW και τη βελτίωση της απόδοσης εγγραφής
- Βελτιστοποιήθηκε η εμπειρία ελέγχου ταυτότητας. Μετά την επανεκκίνηση της συσκευής, οι χρήστες δεν χρειάζεται πλέον να εισάγουν ξανά τον κωδικό πρόσβασής τους στα περισσότερα σενάρια
- Βελτιστοποιήθηκε η εμφάνιση των πληροφοριών μνήμης στη σελίδα λεπτομερειών της εφαρμογής
