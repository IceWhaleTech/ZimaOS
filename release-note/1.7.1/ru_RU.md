## [1.7.1]

### Security
- Исправлена уязвимость высокого риска в файловых сервисах, чтобы повысить безопасность доступа к файлам и операций с ними

### Added
- Добавлена поддержка сетевого драйвера be2net для сетевых адаптеров Emulex
- Добавлена поддержка азербайджанского языка

### Fixes
- Исправлено аномальное использование памяти в некоторых сценариях операций с файлами
- Исправлена проблема, при которой в некоторых сценариях после вырезания папок могли оставаться пустые папки
- Исправлены проблемы, из-за которых задачи резервного копирования могли завершаться с ошибкой или прерываться в некоторых сценариях
- Исправлена проблема, при которой некоторые задачи, связанные с USB, могли теряться после перезагрузки системы
- Исправлено неточное отображение состояния RAID в некоторых сценариях
- Исправлена проблема, при которой при удалении приложения могла удаляться папка его конфигурации

### Improvements
- Улучшены скорость запуска Docker-контейнеров и эффективность запуска контейнеров
- Улучшен процесс настройки сети во время установки Docker
- Улучшена настройка порта Docker Web URL с более гибкими параметрами портов
- Улучшена совместимость сохранения конфигураций YAML, чтобы сократить сбои, вызванные специальным содержимым
- Улучшено отображение App Store и окон установки приложений
- Улучшена совместимость миграции приложений
- Улучшена обработка URL-адресов Docker для лучшей адаптации к динамическим сетевым средам
