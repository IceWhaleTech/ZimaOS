## [1.7.1]

### 安全
- 修復檔案服務中的高風險安全問題，提升檔案存取與操作安全性

### 新增
- 新增 Emulex 網卡 be2net 網路驅動支援
- 支援亞塞拜然語

### 修復
- 修復部分檔案操作情境下出現記憶體占用異常的問題
- 修復部分情境下剪下資料夾後殘留空資料夾的問題
- 修復備份任務在部分情境下執行異常或中斷的問題
- 修復系統重新啟動後部分 USB 相關任務遺失的問題
- 修復部分情境下 RAID 狀態顯示不準確的問題
- 修復解除安裝應用時會刪除應用設定資料夾的問題

### 優化
- 優化 Docker 容器啟動速度，提升容器啟動效率
- 優化 Docker 安裝時的網路設定體驗
- 優化 Docker Web URL 連接埠的設定方式，支援更彈性的連接埠設定
- 優化 YAML 設定儲存的相容性，減少因特殊內容導致儲存失敗的情況
- 優化 App Store 及應用程式安裝相關視窗的顯示體驗
- 優化應用程式遷移的相容性
- 優化 Docker URL 處理邏輯，提升動態網路環境下的適配性
