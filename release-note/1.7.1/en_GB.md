## [1.7.1]

### Security
- Fixed a high-risk security issue in file services to improve the safety of file access and operations

### Added
- Added be2net network driver support for Emulex NICs
- Added support for Azerbaijani

### Fixes
- Fixed abnormal memory usage in certain file operation scenarios
- Fixed an issue where empty folders could remain after cutting folders in certain scenarios
- Fixed issues where backup tasks could fail or be interrupted in certain scenarios
- Fixed an issue where some USB-related tasks could be lost after system restart
- Fixed inaccurate RAID status display in certain scenarios
- Fixed an issue where uninstalling an app could delete the app configuration folder

### Improvements
- Improved Docker container start-up speed and container start-up efficiency
- Improved the network configuration experience during Docker installation
- Improved Docker Web URL port configuration with more flexible port settings
- Improved YAML configuration saving compatibility to reduce failures caused by special content
- Improved the display experience of App Store and app installation windows
- Improved app migration compatibility
- Improved Docker URL handling to better adapt to dynamic network environments
