## [1.7.1]

### Security
- Foi corrigido um problema de segurança de alto risco nos serviços de ficheiros para melhorar a segurança do acesso e das operações com ficheiros

### Added
- Adicionado suporte para o controlador de rede be2net para placas de rede Emulex
- Adicionado suporte para o azerbaijano

### Fixes
- Corrigida a utilização anormal de memória em determinados cenários de operações com ficheiros
- Corrigido um problema em que podiam permanecer pastas vazias depois de cortar pastas em determinados cenários
- Corrigidos problemas em que as tarefas de cópia de segurança podiam falhar ou ser interrompidas em determinados cenários
- Corrigido um problema em que algumas tarefas relacionadas com USB podiam perder-se após o reinício do sistema
- Corrigida a apresentação imprecisa do estado do RAID em determinados cenários
- Corrigido um problema em que a desinstalação de uma aplicação podia eliminar a respetiva pasta de configuração

### Improvements
- A velocidade de arranque dos contentores Docker e a eficiência do arranque dos contentores foram melhoradas
- A experiência de configuração de rede durante a instalação do Docker foi melhorada
- A configuração da porta do Docker Web URL foi melhorada com definições de porta mais flexíveis
- A compatibilidade ao guardar configurações YAML foi melhorada para reduzir falhas causadas por conteúdo especial
- A experiência de apresentação da App Store e das janelas de instalação de aplicações foi melhorada
- A compatibilidade da migração de aplicações foi melhorada
- Melhorado o processamento de URLs do Docker para uma melhor adaptação a ambientes de rede dinâmicos
