## [1.7.1]

### Security
- 파일 서비스의 고위험 보안 문제를 수정해 파일 접근 및 작업의 보안성을 높였습니다

### Added
- Emulex NIC용 be2net 네트워크 드라이버 지원을 추가했습니다
- 아제르바이잔어 지원을 추가했습니다

### Fixes
- 특정 파일 작업 시나리오에서 발생하던 비정상적인 메모리 사용 문제를 수정했습니다
- 특정 시나리오에서 폴더 잘라내기 후 빈 폴더가 남을 수 있던 문제를 수정했습니다
- 특정 시나리오에서 백업 작업이 실패하거나 중단될 수 있던 문제를 수정했습니다
- 시스템 재시작 후 일부 USB 관련 작업이 사라질 수 있던 문제를 수정했습니다
- 특정 시나리오에서 RAID 상태 표시가 부정확하던 문제를 수정했습니다
- 앱을 제거할 때 앱 구성 폴더가 삭제될 수 있던 문제를 수정했습니다

### Improvements
- Docker 컨테이너 시작 속도와 컨테이너 시작 효율을 개선했습니다
- Docker 설치 중 네트워크 구성 경험을 개선했습니다
- Docker Web URL 포트 구성을 개선해 더 유연한 포트 설정을 지원합니다
- 특수한 내용으로 인한 저장 실패를 줄이기 위해 YAML 구성 저장 호환성을 개선했습니다
- App Store 및 앱 설치 관련 창의 표시 경험을 개선했습니다
- 앱 마이그레이션 호환성을 개선했습니다
- 동적 네트워크 환경에 더 잘 대응하도록 Docker URL 처리 방식을 개선했습니다
