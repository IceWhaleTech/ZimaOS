## [1.7.1]

### Security
- Ceartaíodh saincheist slándála ardriosca i seirbhísí comhad chun slándáil rochtana agus oibríochtaí comhad a fheabhsú

### Added
- Cuireadh tacaíocht don tiománaí líonra be2net le haghaidh cártaí líonra Emulex leis
- Cuireadh tacaíocht don Asarbaiseáinis leis

### Fixes
- Ceartaíodh úsáid chuimhne neamhghnách i gcásanna áirithe d’oibríochtaí comhad
- Ceartaíodh saincheist ina bhféadfadh fillteáin fholmha fanacht i ndiaidh fillteáin a ghearradh i gcásanna áirithe
- Ceartaíodh saincheisteanna ina bhféadfadh tascanna cúltaca teip nó cur isteach a bheith orthu i gcásanna áirithe
- Ceartaíodh saincheist ina bhféadfadh roinnt tascanna a bhaineann le USB a bheith caillte tar éis atosaithe an chórais
- Ceartaíodh taispeáint mhíchruinn ar stádas RAID i gcásanna áirithe
- Ceartaíodh saincheist ina bhféadfadh díshuiteáil aip fillteán cumraíochta na haipe a scriosadh

### Improvements
- Feabhsaíodh luas tosaithe coimeádán Docker agus éifeachtúlacht tosaithe coimeádán
- Feabhsaíodh an taithí ar chumraíocht líonra le linn suiteáil Docker
- Feabhsaíodh cumraíocht phoirt Docker Web URL le socruithe poirt níos solúbtha
- Feabhsaíodh comhoiriúnacht shábháil chumraíochtaí YAML chun teipeanna de bharr ábhair speisialta a laghdú
- Feabhsaíodh an taithí taispeána ar App Store agus ar fhuinneoga suiteála aipeanna
- Feabhsaíodh comhoiriúnacht imirce aipeanna
- Feabhsaíodh láimhseáil URL Docker chun oiriúnú níos fearr do thimpeallachtaí líonra dinimiciúla
