## [1.7.1-beta2]

### Improvements

- Docker കണ്ടെയ്‌നറുകളുടെ ആരംഭ വേഗതയും കണ്ടെയ്‌നർ സ്റ്റാർട്ടപ്പ് കാര്യക്ഷമതയും മെച്ചപ്പെടുത്തി

## [1.7.1-beta1]

### Security
- ഫയല്‍ സേവനങ്ങളിലെ ഉയര്‍ന്ന അപകടസാധ്യതയുള്ള ഒരു സുരക്ഷാ പ്രശ്നം പരിഹരിച്ചു, ഫയല്‍ ആക്‌സസിന്റെയും പ്രവര്‍ത്തനങ്ങളുടെയും സുരക്ഷ മെച്ചപ്പെടുത്തി

### Fixes
- ചില ഫയല്‍ പ്രവര്‍ത്തന സാഹചര്യങ്ങളില്‍ ഉണ്ടായിരുന്ന അസാധാരണമായ മെമ്മറി ഉപയോഗം പരിഹരിച്ചു
- ചില സാഹചര്യങ്ങളില്‍ ഫോള്‍ഡറുകള്‍ മുറിച്ചുമാറ്റിയതിന് ശേഷം ശൂന്യ ഫോള്‍ഡറുകള്‍ ശേഷിക്കാവുന്ന പ്രശ്നം പരിഹരിച്ചു
- ചില സാഹചര്യങ്ങളില്‍ ബാക്കപ്പ് ജോലികള്‍ പരാജയപ്പെടുകയോ തടസപ്പെടുകയോ ചെയ്തിരുന്ന പ്രശ്നങ്ങള്‍ പരിഹരിച്ചു
- സിസ്റ്റം റീസ്റ്റാര്‍ട്ട് ചെയ്ത ശേഷം ചില USB അനുബന്ധ ജോലികള്‍ നഷ്ടപ്പെടാവുന്ന പ്രശ്നം പരിഹരിച്ചു
- ചില സാഹചര്യങ്ങളില്‍ RAID നില കൃത്യമായി പ്രദര്‍ശിപ്പിക്കാത്ത പ്രശ്നം പരിഹരിച്ചു
- ഒരു ആപ്പ് അണ്‍ഇന്‍സ്റ്റാള്‍ ചെയ്യുമ്പോള്‍ അതിന്റെ അപ്ലിക്കേഷന്‍ ഡാറ്റയും മായ്ക്കപ്പെടുന്ന പ്രശ്നം പരിഹരിച്ചു

### Improvements
- Docker ഇന്‍സ്റ്റാളേഷന്‍ സമയത്തെ നെറ്റ്‌വര്‍ക്ക് കോണ്‍ഫിഗറേഷന്‍ അനുഭവം മെച്ചപ്പെടുത്തി
- Docker Web URL പോര്‍ട്ട് കോണ്‍ഫിഗറേഷന്‍ മെച്ചപ്പെടുത്തി, കൂടുതല്‍ ഇളവുള്ള പോര്‍ട്ട് ക്രമീകരണങ്ങള്‍ പിന്തുണയ്ക്കുന്നു
- പ്രത്യേക ഉള്ളടക്കം മൂലമുള്ള സേവ് പരാജയങ്ങള്‍ കുറയ്ക്കാന്‍ YAML കോണ്‍ഫിഗറേഷന്‍ സേവിംഗ് പൊരുത്തക്ഷമത മെച്ചപ്പെടുത്തി
- App Storeയും ആപ്പ് ഇന്‍സ്റ്റാളേഷന്‍ വിന്‍ഡോകളും സംബന്ധിച്ച പ്രദര്‍ശന അനുഭവം മെച്ചപ്പെടുത്തി
- ആപ്പ് മൈഗ്രേഷന്‍ പൊരുത്തക്ഷമത മെച്ചപ്പെടുത്തി
