## [1.7.1-beta1]

### Security
- Διορθώθηκε ένα ζήτημα ασφαλείας υψηλού κινδύνου στις υπηρεσίες αρχείων για τη βελτίωση της ασφάλειας της πρόσβασης και των λειτουργιών αρχείων

### Fixes
- Διορθώθηκε η μη φυσιολογική χρήση μνήμης σε ορισμένα σενάρια λειτουργιών αρχείων
- Διορθώθηκε ένα ζήτημα όπου σε ορισμένα σενάρια μπορούσαν να παραμένουν άδειοι φάκελοι μετά την αποκοπή φακέλων
- Διορθώθηκαν ζητήματα όπου οι εργασίες αντιγράφων ασφαλείας μπορούσαν να αποτυγχάνουν ή να διακόπτονται σε ορισμένα σενάρια
- Διορθώθηκε ένα ζήτημα όπου ορισμένες εργασίες σχετικές με USB μπορούσαν να χαθούν μετά από επανεκκίνηση του συστήματος
- Διορθώθηκε η ανακριβής εμφάνιση της κατάστασης RAID σε ορισμένα σενάρια
- Διορθώθηκε ένα ζήτημα όπου η απεγκατάσταση μιας εφαρμογής διέγραφε τα δεδομένα της

### Improvements
- Βελτιώθηκε η εμπειρία ρύθμισης δικτύου κατά την εγκατάσταση του Docker
- Βελτιώθηκε η διαμόρφωση θυρών του Docker Web URL με πιο ευέλικτες ρυθμίσεις θυρών
- Βελτιώθηκε η συμβατότητα αποθήκευσης ρυθμίσεων YAML ώστε να μειωθούν οι αστοχίες που προκαλούνται από ειδικό περιεχόμενο
- Βελτιώθηκε η εμπειρία προβολής του App Store και των παραθύρων εγκατάστασης εφαρμογών
- Βελτιώθηκε η συμβατότητα μετεγκατάστασης εφαρμογών
