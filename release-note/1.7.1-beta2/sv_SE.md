### Improvements

## [1.7.1-beta1]

### Security
- Ett säkerhetsproblem med hög risk i filtjänsterna åtgärdades för att förbättra säkerheten vid filåtkomst och filoperationer

### Fixes
- Åtgärdade onormal minnesanvändning i vissa scenarier för filoperationer
- Åtgärdade ett problem där tomma mappar kunde bli kvar efter att mappar klippts ut i vissa scenarier
- Åtgärdade problem där säkerhetskopieringsuppgifter kunde misslyckas eller avbrytas i vissa scenarier
- Åtgärdade ett problem där vissa USB-relaterade uppgifter kunde gå förlorade efter omstart av systemet
- Åtgärdade felaktig visning av RAID-status i vissa scenarier
- Åtgärdade ett problem där avinstallation av en app raderade dess applikationsdata

### Improvements
- Förbättrade nätverkskonfigurationsupplevelsen under installation av Docker
- Förbättrade konfigurationen av Docker Web URL-portar med mer flexibla portinställningar
- Förbättrade kompatibiliteten vid sparande av YAML-konfigurationer för att minska fel som orsakas av särskilt innehåll
- Förbättrade visningsupplevelsen för App Store och fönster för appinstallation
- Förbättrade kompatibiliteten vid appmigrering
