## [1.7.1-beta2]

### Improvements

- È stata migliorata la velocità di avvio dei container Docker e l'efficienza di avvio dei container

## [1.7.1-beta1]

### Security
- È stato corretto un problema di sicurezza ad alto rischio nei servizi file per migliorare la sicurezza dell'accesso e delle operazioni sui file

### Fixes
- Risolto l'uso anomalo della memoria in determinati scenari di operazioni sui file
- Risolto un problema per cui in determinati scenari potevano rimanere cartelle vuote dopo il taglio di cartelle
- Risolti problemi per cui le attività di backup potevano fallire o interrompersi in determinati scenari
- Risolto un problema per cui alcune attività correlate a USB potevano andare perse dopo il riavvio del sistema
- Risolta la visualizzazione imprecisa dello stato RAID in determinati scenari
- Risolto un problema per cui la disinstallazione di un'app eliminava i suoi dati applicativi

### Improvements
- Migliorata l'esperienza di configurazione della rete durante l'installazione di Docker
- Migliorata la configurazione della porta Docker Web URL con impostazioni di porta più flessibili
- Migliorata la compatibilità del salvataggio delle configurazioni YAML per ridurre i fallimenti causati da contenuti speciali
- Migliorata l'esperienza visiva dell'App Store e delle finestre di installazione delle app
- Migliorata la compatibilità della migrazione delle app
