## [1.8.0-beta2]

### Added
- Spotlight のサポートを追加し、Spotlight からデバイスの関連機能やコンテンツをすばやく検索してアクセスできるようにしました。

### Fixed
- マップデータが自動的に読み込まれない問題を修正しました。クリックしなくてもマップが表示され、ページを更新してもデータが保持されるようになりました。
- パノラマ動画のプレビューがタイムアウトした際に、「動画を利用できません」というメッセージが誤って表示される問題を修正しました。
- CPU モードでインデックス作成の進捗が不正確に表示される問題と、進捗更新を受信した後にステータスが正しく読み込まれない問題を修正しました。
- シンボリックリンクを含むディレクトリにアクセスすると、「外部リンクが切れています」というメッセージが誤って表示される問題を修正しました。
- パノラマ動画の再生中にシークすると、動画が予期せず一時停止する問題を修正しました。
- ページ右上のスクロールバー領域がすりガラス効果のコントロールに覆われ、クリックできない問題を修正しました。
- 特定の状況でアプリのインストールに失敗する問題を修正しました。
- 更新が不要なアプリに更新可能と誤って表示されることがある、アプリ更新ステータスの検出問題を修正しました。

### Optimized
- Embedding データテーブルの作成を遅延させることで起動処理を最適化し、モデルのダウンロードによってアプリの起動が妨げられないようにして、初回起動時のパフォーマンスを向上させました。
- Gallery ページのレイアウトを最適化しました。ページの高さを Masonry レイアウトに合わせ、利用可能な表示領域をより有効に活用できるようにしました。
- ユーザー認証体験を最適化しました。デバイスの再起動後、ほとんどの状況でパスワードを再入力する必要がなくなりました。
- アプリ詳細ページに表示されるメモリ情報を最適化しました。

## [1.8.0-beta1]

### Added
- 写真ソースの追加に対応し、写真と動画を統合されたタイムラインで閲覧できるフォトライブラリを追加しました
- 自然言語、画像内のテキスト、視覚的な内容を使って写真を検索できるスマート検索を追加しました
- 国や地域、都市、場所ごとに写真を表示できるマップ閲覧機能を追加しました
- 重要な項目を整理して見つけやすくするため、アルバム、お気に入り、最近表示した項目を追加しました
- 「この日の思い出」、場所の思い出、旅行ストーリーを自動的に整理するメモリーズを追加しました
- iCloud Drive、iCloud Photos、Baidu Netdisk との連携を追加しました
- 一部のデバイス向けにファン制御戦略を追加し、冷却性能と動作の安定性を向上させました

### Fixes
- システムのタイムゾーンを変更できない問題を修正しました
- デバイス情報に表示されるメモリ周波数が実際の周波数と一致しない問題を修正しました
- RAID 作成ウィンドウ下部の「作成」ボタンが一部の状況で隠れる問題を修正しました
- 一部の状況でバックアップタスクがシステムリソースを過剰に消費する問題を修正しました

### Improvements
- Docker アプリの起動、終了、状態遷移の信頼性を高めるため、アプリのライフサイクル管理を最適化しました
- アプリ設定ページの CPU リソース上限ロジックを最適化しました。最大値はデバイス情報で検出された CPU スレッド数に基づいて決定されます
- アプリのアンインストールフローを最適化し、アプリデータを削除するか保持するか選択できるようにしました
