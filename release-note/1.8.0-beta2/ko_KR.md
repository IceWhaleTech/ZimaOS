## [1.8.0-beta2]

### Added
- Spotlight 지원을 추가하여 Spotlight를 통해 기기의 관련 기능과 콘텐츠를 빠르게 검색하고 이용할 수 있도록 했습니다.

### Fixed
- 지도 데이터가 자동으로 로드되지 않던 문제를 수정했습니다. 이제 클릭하지 않아도 지도가 표시되며 페이지를 새로 고친 후에도 데이터가 유지됩니다.
- 파노라마 동영상 미리보기 시간이 초과될 때 “동영상을 사용할 수 없음” 메시지가 잘못 표시되던 문제를 수정했습니다.
- CPU 모드에서 인덱싱 진행률이 부정확하게 표시되던 문제와 진행률 업데이트를 받은 후 상태가 올바르게 로드되지 않던 문제를 수정했습니다.
- 심볼릭 링크가 포함된 디렉터리에 접근할 때 “외부 링크가 끊어졌습니다” 메시지가 잘못 표시되던 문제를 수정했습니다.
- 파노라마 동영상 재생 중 탐색하면 동영상이 예기치 않게 일시 중지되던 문제를 수정했습니다.
- 페이지 오른쪽 상단의 스크롤바 영역이 반투명 유리 효과 컨트롤에 가려져 클릭할 수 없던 문제를 수정했습니다.
- 특정 상황에서 앱 설치가 실패하던 문제를 수정했습니다.
- 업데이트가 필요하지 않은 앱에 업데이트가 있다고 잘못 표시될 수 있던 앱 업데이트 상태 감지 문제를 수정했습니다.

### Optimized
- Embedding 데이터 테이블 생성을 지연하도록 시작 프로세스를 최적화하여 모델 다운로드가 앱 시작을 차단하지 않도록 하고 최초 실행 성능을 개선했습니다.
- Gallery 페이지 레이아웃을 최적화했습니다. 페이지 높이가 Masonry 레이아웃과 일치하도록 조정되어 사용 가능한 표시 영역을 더 효율적으로 활용합니다.
- 사용자 인증 경험을 최적화했습니다. 기기를 다시 시작한 후 대부분의 상황에서 비밀번호를 다시 입력할 필요가 없습니다.
- 앱 상세 페이지에 표시되는 메모리 정보를 최적화했습니다.

## [1.8.0-beta1]

### Added
- 사진 소스를 추가하고 사진과 동영상을 통합 타임라인에서 탐색할 수 있는 사진 라이브러리를 추가했습니다
- 자연어, 이미지 속 텍스트, 시각적 콘텐츠를 사용해 사진을 찾을 수 있는 스마트 검색을 추가했습니다
- 국가 또는 지역, 도시, 위치별로 사진을 볼 수 있는 지도 탐색 기능을 추가했습니다
- 중요한 항목을 더 쉽게 정리하고 찾을 수 있도록 앨범, 즐겨찾기, 최근 본 항목을 추가했습니다
- 오늘의 추억, 위치 추억, 여행 이야기를 자동으로 정리하는 추억 기능을 추가했습니다
- iCloud Drive, iCloud Photos, Baidu Netdisk 통합을 추가했습니다
- 일부 기기에 팬 제어 전략을 추가하여 냉각 성능과 작동 안정성을 향상했습니다

### Fixes
- 시스템 시간대를 변경할 수 없던 문제를 수정했습니다
- 장치 정보에 표시되는 메모리 주파수가 실제 주파수와 일치하지 않던 문제를 수정했습니다
- 일부 상황에서 RAID 생성 창 하단의 만들기 버튼이 가려질 수 있던 문제를 수정했습니다
- 일부 상황에서 백업 작업이 시스템 리소스를 과도하게 사용하던 문제를 수정했습니다

### Improvements
- 앱 시작, 종료 및 상태 전환의 안정성을 높이기 위해 Docker 앱 수명 주기 관리를 최적화했습니다
- 앱 구성 페이지의 CPU 리소스 제한 로직을 최적화했습니다. 이제 최대값은 장치 정보에서 감지된 CPU 스레드 수를 기준으로 결정됩니다
- 앱 제거 흐름을 최적화하여 앱 데이터를 삭제할지 유지할지 선택할 수 있도록 했습니다
