## [1.8.0-beta2]

### Added
- Добавлена поддержка Spotlight, позволяющая быстро искать и открывать соответствующие функции и содержимое устройства через Spotlight.

### Fixed
- Исправлена проблема, при которой данные карты не загружались автоматически. Теперь карты отображаются без необходимости щелчка, а данные сохраняются после обновления страницы.
- Исправлена проблема, при которой при истечении времени ожидания предварительного просмотра панорамного видео ошибочно отображалось сообщение «Видео недоступно».
- Исправлено неточное отображение хода индексирования в режиме CPU, а также проблема, при которой состояние загружалось некорректно после получения обновления прогресса.
- Исправлена проблема, при которой при доступе к каталогам с символическими ссылками ошибочно отображалось сообщение «Внешняя ссылка не работает».
- Исправлена проблема, при которой перемещение по панорамному видео во время воспроизведения неожиданно приостанавливало его.
- Исправлена проблема, при которой область полосы прокрутки в правом верхнем углу страницы перекрывалась элементом управления с эффектом матового стекла и была недоступна для нажатия.
- Исправлены ошибки установки приложений в некоторых сценариях.
- Исправлена проблема определения состояния обновлений приложений, из-за которой для приложений, не требующих обновления, могло ошибочно отображаться доступное обновление.

### Optimized
- Оптимизирован процесс запуска: создание таблицы данных embeddings отложено, чтобы загрузка модели не блокировала запуск приложения и повысилась производительность при первом запуске.
- Оптимизирован макет страницы Gallery. Высота страницы теперь соответствует макету Masonry, что позволяет эффективнее использовать доступную область просмотра.
- Оптимизирован процесс аутентификации. После перезапуска устройства в большинстве сценариев пользователям больше не требуется повторно вводить пароль.
- Оптимизировано отображение информации о памяти на странице сведений о приложении.

## [1.8.0-beta1]

### Added
- Добавлена фотобиблиотека с поддержкой добавления источников фотографий и просмотра фотографий и видео на единой временной шкале
- Добавлен интеллектуальный поиск, позволяющий находить фотографии с помощью естественного языка, текста на изображениях и визуального содержимого
- Добавлен просмотр на карте, позволяющий просматривать фотографии по стране или региону, городу и местоположению
- Добавлены альбомы, избранное и недавно просмотренные элементы для упрощения организации и поиска важных элементов
- Добавлены воспоминания, которые автоматически упорядочивают подборки «В этот день», воспоминания о местах и истории путешествий
- Добавлена интеграция с iCloud Drive, iCloud Photos и Baidu Netdisk
- Добавлены стратегии управления вентиляторами для выбранных устройств, улучшающие охлаждение и стабильность работы

### Fixes
- Исправлена проблема, из-за которой пользователи не могли изменить часовой пояс системы
- Исправлена проблема, при которой частота памяти, отображаемая в информации об устройстве, не соответствовала фактической частоте
- Исправлена проблема, при которой кнопка «Создать» в нижней части окна создания RAID могла быть скрыта в некоторых сценариях
- Исправлена проблема, из-за которой задачи резервного копирования в некоторых сценариях потребляли чрезмерное количество системных ресурсов

### Improvements
- Оптимизировано управление жизненным циклом Docker-приложений для повышения надежности запуска, остановки и переходов между состояниями приложений
- Оптимизирована логика ограничения ресурсов CPU на странице конфигурации приложения. Максимальное значение теперь определяется на основе количества потоков CPU, обнаруженных в информации об устройстве
- Оптимизирован процесс удаления приложений, позволяющий выбрать, удалить или сохранить данные приложения
