## [1.8.0-beta2]

### Added
- Spotlight വഴി ഉപകരണത്തിലെ പ്രസക്തമായ ഫീച്ചറുകളും ഉള്ളടക്കവും വേഗത്തിൽ തിരയാനും ആക്സസ് ചെയ്യാനും അനുവദിക്കുന്ന Spotlight പിന്തുണ ചേർത്തു.

### Fixed
- മാപ്പ് ഡാറ്റ സ്വയമേവ ലോഡ് ആകാത്ത പ്രശ്നം പരിഹരിച്ചു. ഇപ്പോൾ ക്ലിക്ക് ചെയ്യാതെ തന്നെ മാപ്പുകൾ പ്രദർശിപ്പിക്കുകയും പേജ് പുതുക്കിയ ശേഷവും ഡാറ്റ നിലനിർത്തുകയും ചെയ്യുന്നു.
- പനോരമിക് വീഡിയോ പ്രിവ്യൂ ടൈംഔട്ട് ആകുമ്പോൾ “വീഡിയോ ലഭ്യമല്ല” എന്ന സന്ദേശം തെറ്റായി പ്രദർശിപ്പിച്ച പ്രശ്നം പരിഹരിച്ചു.
- CPU മോഡിൽ ഇൻഡെക്സിംഗ് പുരോഗതി തെറ്റായി പ്രദർശിപ്പിച്ച പ്രശ്നവും പുരോഗതി അപ്ഡേറ്റ് ലഭിച്ചതിന് ശേഷം സ്റ്റാറ്റസ് ശരിയായി ലോഡ് ആകാത്ത പ്രശ്നവും പരിഹരിച്ചു.
- സിംബോളിക് ലിങ്കുകൾ അടങ്ങിയ ഡയറക്ടറികൾ ആക്സസ് ചെയ്യുമ്പോൾ “ബാഹ്യ ലിങ്ക് തകരാറിലാണ്” എന്ന സന്ദേശം തെറ്റായി പ്രദർശിപ്പിച്ച പ്രശ്നം പരിഹരിച്ചു.
- പനോരമിക് വീഡിയോ പ്ലേബാക്കിനിടെ മറ്റൊരു സ്ഥാനത്തേക്ക് നീങ്ങുമ്പോൾ വീഡിയോ അപ്രതീക്ഷിതമായി താൽക്കാലികമായി നിർത്തിയ പ്രശ്നം പരിഹരിച്ചു.
- പേജിന്റെ മുകളിൽ വലത് കോണിലുള്ള സ്ക്രോൾബാർ പ്രദേശം ഫ്രോസ്റ്റഡ് ഗ്ലാസ് കൺട്രോൾ മറയ്ക്കുകയും ക്ലിക്ക് ചെയ്യാൻ കഴിയാതിരിക്കുകയും ചെയ്ത പ്രശ്നം പരിഹരിച്ചു.
- ചില സാഹചര്യങ്ങളിലെ ആപ്പ് ഇൻസ്റ്റാളേഷൻ പരാജയങ്ങൾ പരിഹരിച്ചു.
- അപ്ഡേറ്റ് ആവശ്യമില്ലാത്ത ആപ്പുകൾക്ക് അപ്ഡേറ്റ് ലഭ്യമാണെന്ന് തെറ്റായി സൂചിപ്പിക്കാവുന്ന ആപ്പ് അപ്ഡേറ്റ് സ്റ്റാറ്റസ് കണ്ടെത്തൽ പ്രശ്നം പരിഹരിച്ചു.

### Optimized
- Embedding ഡാറ്റാ ടേബിൾ സൃഷ്ടിക്കുന്നത് വൈകിപ്പിച്ച് സ്റ്റാർട്ടപ്പ് പ്രക്രിയ ഒപ്റ്റിമൈസ് ചെയ്തു; ഇതുവഴി മോഡൽ ഡൗൺലോഡുകൾ ആപ്പ് സ്റ്റാർട്ടപ്പിനെ തടയുന്നത് ഒഴിവാക്കി ആദ്യ ലോഞ്ച് പ്രകടനം മെച്ചപ്പെടുത്തി.
- Gallery പേജ് ലേഔട്ട് ഒപ്റ്റിമൈസ് ചെയ്തു. പേജ് ഉയരം ഇപ്പോൾ Masonry ലേഔട്ടുമായി പൊരുത്തപ്പെടുന്നതിനാൽ ലഭ്യമായ കാഴ്ചാ പ്രദേശം കൂടുതൽ ഫലപ്രദമായി ഉപയോഗിക്കുന്നു.
- ഉപയോക്തൃ ഓതന്റിക്കേഷൻ അനുഭവം ഒപ്റ്റിമൈസ് ചെയ്തു. ഉപകരണം പുനരാരംഭിച്ചതിന് ശേഷം മിക്ക സാഹചര്യങ്ങളിലും ഉപയോക്താക്കൾ വീണ്ടും പാസ്‌വേഡ് നൽകേണ്ടതില്ല.
- ആപ്പ് വിശദാംശ പേജിൽ പ്രദർശിപ്പിക്കുന്ന മെമ്മറി വിവരങ്ങൾ ഒപ്റ്റിമൈസ് ചെയ്തു.

## [1.8.0-beta1]

### Added
- ഫോട്ടോ ഉറവിടങ്ങൾ ചേർക്കാനും ഫോട്ടോകളും വീഡിയോകളും ഏകീകൃത ടൈംലൈനിൽ ബ്രൗസ് ചെയ്യാനും പിന്തുണയ്ക്കുന്ന ഫോട്ടോ ലൈബ്രറി ചേർത്തു
- സ്വാഭാവിക ഭാഷ, ചിത്രങ്ങളിലെ ടെക്സ്റ്റ്, ദൃശ്യ ഉള്ളടക്കം എന്നിവ ഉപയോഗിച്ച് ഫോട്ടോകൾ കണ്ടെത്താൻ അനുവദിക്കുന്ന Smart Search ചേർത്തു
- രാജ്യം അല്ലെങ്കിൽ പ്രദേശം, നഗരം, സ്ഥലം എന്നിവ അനുസരിച്ച് ഫോട്ടോകൾ കാണാൻ അനുവദിക്കുന്ന മാപ്പ് ബ്രൗസിംഗ് ചേർത്തു
- പ്രധാനപ്പെട്ട ഇനങ്ങൾ എളുപ്പത്തിൽ ക്രമീകരിക്കാനും കണ്ടെത്താനും ആൽബങ്ങൾ, പ്രിയപ്പെട്ടവ, അടുത്തിടെ കണ്ട ഇനങ്ങൾ എന്നിവ ചേർത്തു
- On This Day ഹൈലൈറ്റുകൾ, സ്ഥല ഓർമ്മകൾ, യാത്രാ കഥകൾ എന്നിവ സ്വയമേവ ക്രമീകരിക്കുന്ന Memories ചേർത്തു
- iCloud Drive, iCloud Photos, Baidu Netdisk സംയോജനം ചേർത്തു
- തിരഞ്ഞെടുത്ത ഉപകരണങ്ങൾക്കായി കൂളിംഗ് പ്രകടനവും പ്രവർത്തന സ്ഥിരതയും മെച്ചപ്പെടുത്തുന്ന ഫാൻ നിയന്ത്രണ തന്ത്രങ്ങൾ ചേർത്തു

### Fixes
- സിസ്റ്റം സമയമേഖല മാറ്റുന്നതിൽ നിന്ന് ഉപയോക്താക്കളെ തടഞ്ഞ പ്രശ്നം പരിഹരിച്ചു
- Device Info-യിൽ കാണിച്ച മെമ്മറി ഫ്രീക്വൻസി യഥാർത്ഥ ഫ്രീക്വൻസിയുമായി പൊരുത്തപ്പെടാത്ത പ്രശ്നം പരിഹരിച്ചു
- ചില സാഹചര്യങ്ങളിൽ RAID സൃഷ്ടിക്കൽ വിൻഡോയുടെ താഴെയുള്ള Create ബട്ടൺ മറഞ്ഞുപോകാവുന്ന പ്രശ്നം പരിഹരിച്ചു
- ചില സാഹചര്യങ്ങളിൽ ബാക്കപ്പ് ടാസ്കുകൾ അമിതമായ സിസ്റ്റം വിഭവങ്ങൾ ഉപയോഗിച്ച പ്രശ്നം പരിഹരിച്ചു

### Improvements
- ആപ്പ് സ്റ്റാർട്ട്, ഷട്ട്ഡൗൺ, സ്റ്റേറ്റ് മാറ്റങ്ങൾ എന്നിവയുടെ വിശ്വാസ്യത മെച്ചപ്പെടുത്തുന്നതിനായി Docker ആപ്പ് ലൈഫ്‌സൈക്കിൾ മാനേജ്മെന്റ് ഒപ്റ്റിമൈസ് ചെയ്തു
- ആപ്പ് കോൺഫിഗറേഷൻ പേജിലെ CPU റിസോഴ്സ് പരിധി ലോജിക് ഒപ്റ്റിമൈസ് ചെയ്തു. Device Info-യിൽ കണ്ടെത്തുന്ന CPU ത്രെഡുകളുടെ എണ്ണത്തെ അടിസ്ഥാനമാക്കിയാണ് പരമാവധി മൂല്യം ഇപ്പോൾ നിർണ്ണയിക്കുന്നത്
- ആപ്പ് അൺഇൻസ്റ്റാൾ പ്രവാഹം ഒപ്റ്റിമൈസ് ചെയ്തു; ആപ്പ് ഡാറ്റ ഇല്ലാതാക്കണോ നിലനിർത്തണോ എന്ന് തിരഞ്ഞെടുക്കാൻ ഉപയോക്താക്കൾക്ക് കഴിയും
