## [1.8.0-beta2]

### 新增
- 新增 Spotlight 功能支持，可通过 Spotlight 快速搜索和访问设备中的相关功能与内容

### 修复
- 修复地图数据未自动加载的问题：无需点击即可正常显示，刷新页面后数据也不会丢失
- 修复全景视频预览超时时错误提示“视频不可用”的问题
- 修复 CPU 模式下索引进度显示不准确，以及收到进度推送后状态未正确加载的问题
- 修复访问包含软链接的目录时，错误提示“外部链接已断开”的问题
- 修复全景视频播放过程中进行拖拽操作会意外触发暂停的问题
- 修复页面右上角滚动条区域被毛玻璃控件遮挡，导致无法点击的问题
- 修复部分场景下应用安装失败的问题
- 修复应用升级状态判断异常的问题，避免无需升级的应用被错误提示为可更新

### 优化
- 优化启动流程：延迟创建 Embedding 数据表，避免因下载模型阻塞应用启动，提升首次启动速度
- 优化 Gallery 页面布局：页面高度调整为与瀑布流模式一致，充分利用可视区域
- 优化用户鉴权体验，设备重启后，在大多数场景下无需再次输入密码
- 优化应用详情页的内存信息展示

## [1.8.0-beta1]

### 新增
- 新增图库功能，支持添加照片来源，并按时间线集中浏览照片和视频
- 新增智能搜索，支持通过自然语言、图片文字和画面内容查找照片
- 新增地图浏览，可按国家或地区、城市和地点查看照片
- 新增相册、收藏与最近浏览，帮助用户更方便地整理和查找重要照片
- 新增记忆功能，自动整理往年今日、地点回忆和旅程故事
- 新增 iCloud Drive、iCloud Photos 及百度网盘接入支持
- 新增部分设备的风扇控制策略，提升散热表现与运行稳定性

### 修复
- 修复无法修改系统时区的问题
- 修复设备信息中显示的内存频率与实际频率不一致的问题
- 修复创建 RAID 时，部分场景下窗口底部“创建”按钮可能被遮挡的问题
- 修复部分场景下备份任务资源占用过高的问题

### 优化
- 优化 Docker 应用生命周期管理，提升应用启动、停止及状态切换的可靠性
- 优化应用配置页面的 CPU 资源上限逻辑，上限将根据设备信息中识别到的 CPU 线程数自动确定
- 优化应用卸载流程，支持在卸载时选择删除或保留应用数据
