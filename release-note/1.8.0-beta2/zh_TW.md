## [1.8.0-beta2]

### 新增
- 新增 Spotlight 功能支援，可透過 Spotlight 快速搜尋及存取裝置中的相關功能與內容

### 修復
- 修復地圖資料未自動載入的問題，現在無需點擊即可正常顯示，重新整理頁面後資料也不會遺失
- 修復全景影片預覽逾時時，錯誤顯示「影片無法使用」提示的問題
- 修復 CPU 模式下索引進度顯示不準確，以及收到進度推送後狀態未正確載入的問題
- 修復存取包含符號連結的目錄時，錯誤顯示「外部連結已中斷」提示的問題
- 修復全景影片播放期間拖曳進度列時，意外觸發暫停的問題
- 修復頁面右上角捲軸區域遭毛玻璃控制項遮擋，導致無法點擊的問題
- 修復部分情境下應用程式安裝失敗的問題
- 修復應用程式更新狀態判斷異常的問題，避免無需更新的應用程式被錯誤提示為可更新

### 優化
- 優化啟動流程：延後建立 Embedding 資料表，避免下載模型時阻塞應用程式啟動，提升首次啟動速度
- 優化圖庫頁面配置：頁面高度調整為與瀑布流模式一致，充分利用可視區域
- 優化使用者驗證體驗，裝置重新啟動後，在大多數情境下無需再次輸入密碼
- 優化應用程式詳細資訊頁面的記憶體資訊顯示

## [1.8.0-beta1]

### 新增
- 新增圖庫功能，支援新增照片來源，並可透過時間軸集中瀏覽照片與影片
- 新增智慧搜尋，支援透過自然語言、圖片中的文字及畫面內容尋找照片
- 新增地圖瀏覽，可依國家或地區、城市及地點查看照片
- 新增相簿、收藏與最近瀏覽，協助使用者更方便地整理及尋找重要照片
- 新增回憶功能，自動整理往年今日、地點回憶及旅程故事
- 新增 iCloud Drive、iCloud Photos 及百度網盤整合支援
- 新增部分裝置的風扇控制策略，提升散熱表現與運作穩定性

### 修復
- 修復無法修改系統時區的問題
- 修復裝置資訊中顯示的記憶體頻率與實際頻率不一致的問題
- 修復在部分情境下建立 RAID 時，視窗底部的「建立」按鈕可能被遮擋的問題
- 修復在部分情境下備份工作佔用過多系統資源的問題

### 優化
- 優化 Docker 應用程式生命週期管理，提升應用程式啟動、停止及狀態切換的可靠性
- 優化應用程式設定頁面的 CPU 資源上限邏輯，最高值會根據裝置資訊中偵測到的 CPU 執行緒數量自動判定
- 優化應用程式解除安裝流程，支援選擇刪除或保留應用程式資料
