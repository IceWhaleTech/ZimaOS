## [1.7.1-beta1]

### Security
- ファイルサービスにおける高リスクなセキュリティ問題を修正し、ファイルアクセスと操作の安全性を向上させました

### Fixes
- 一部のファイル操作シナリオで発生する異常なメモリ使用を修正しました
- 特定のシナリオでフォルダを切り取りした後に空のフォルダが残る問題を修正しました
- 特定のシナリオでバックアップタスクが失敗または中断する問題を修正しました
- システム再起動後に一部の USB 関連タスクが失われる問題を修正しました
- 特定のシナリオで RAID 状態の表示が不正確になる問題を修正しました
- アプリをアンインストールするとそのアプリのデータまで削除される問題を修正しました

### Improvements
- Docker インストール時のネットワーク設定体験を改善しました
- Docker Web URL のポート設定を改善し、より柔軟なポート設定に対応しました
- 特殊な内容による保存失敗を減らすため、YAML 設定保存の互換性を改善しました
- App Store とアプリインストール関連ウィンドウの表示体験を改善しました
- アプリ移行の互換性を改善しました
