## [1.7.1-beta1]

### Security
- S'ha corregit un problema de seguretat d'alt risc als serveis de fitxers per millorar la seguretat de l'accés i de les operacions amb fitxers

### Fixes
- S'ha corregit l'ús anòmal de memòria en determinats escenaris d'operacions amb fitxers
- S'ha corregit un problema pel qual en alguns escenaris podien quedar carpetes buides després de retallar carpetes
- S'han corregit problemes pels quals les tasques de còpia de seguretat podien fallar o interrompre's en determinats escenaris
- S'ha corregit un problema pel qual algunes tasques relacionades amb USB es podien perdre després de reiniciar el sistema
- S'ha corregit la visualització inexacta de l'estat del RAID en determinats escenaris
- S'ha corregit un problema pel qual en desinstal·lar una aplicació se n'eliminaven les dades

### Improvements
- S'ha millorat l'experiència de configuració de xarxa durant la instal·lació de Docker
- S'ha millorat la configuració del port de Docker Web URL amb ajustos de port més flexibles
- S'ha millorat la compatibilitat del desament de configuracions YAML per reduir errors causats per contingut especial
- S'ha millorat l'experiència visual de l'App Store i de les finestres d'instal·lació d'aplicacions
- S'ha millorat la compatibilitat de la migració d'aplicacions
