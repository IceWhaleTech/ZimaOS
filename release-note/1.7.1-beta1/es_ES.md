## [1.7.1-beta1]

### Security
- Se corrigió un problema de seguridad de alto riesgo en los servicios de archivos para mejorar la seguridad del acceso y las operaciones con archivos

### Fixes
- Se corrigió el uso anómalo de memoria en determinados escenarios de operaciones con archivos
- Se corrigió un problema por el que podían quedar carpetas vacías después de cortar carpetas en determinados escenarios
- Se corrigieron problemas por los que las tareas de copia de seguridad podían fallar o interrumpirse en determinados escenarios
- Se corrigió un problema por el que algunas tareas relacionadas con USB podían perderse después de reiniciar el sistema
- Se corrigió la visualización inexacta del estado de RAID en determinados escenarios
- Se corrigió un problema por el que al desinstalar una aplicación se eliminaban sus datos

### Improvements
- Se mejoró la experiencia de configuración de red durante la instalación de Docker
- Se mejoró la configuración del puerto Docker Web URL con ajustes de puertos más flexibles
- Se mejoró la compatibilidad al guardar configuraciones YAML para reducir los fallos causados por contenido especial
- Se mejoró la experiencia visual de la App Store y de las ventanas de instalación de aplicaciones
- Se mejoró la compatibilidad de la migración de aplicaciones
