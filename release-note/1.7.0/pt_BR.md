## [1.7.0]

### Added
- A App Store foi redesenhada com uma nova interface para oferecer uma experiência de navegação de aplicativos mais moderna e clara
- Foi adicionada uma página de gerenciamento de aplicativos para administrar aplicativos instalados, status de atualização e ações comuns em um só lugar
- Foi adicionada uma página de descoberta de aplicativos com recomendações aprimoradas, navegação por categorias e apresentação de conteúdo
- Foi adicionado suporte nativo a YAML para uma melhor experiência de edição e interpretação de configurações

### Fixed
- Corrigida a sobreposição da contagem de arquivos na página de backup
- Corrigida a lentidão ao fazer backup de arquivos grandes

### Improved
- A experiência de visualização das listas de aplicativos, páginas de categorias e páginas de detalhes de aplicativos foi aprimorada
- A exibição de logs de contêineres foi aprimorada para oferecer melhor legibilidade e eficiência na solução de problemas
- As operações de terminal de contêiner foram aprimoradas com status de execução mais claro e melhor feedback interativo
- A lógica de detecção de licenças comerciais foi aprimorada para melhor compatibilidade e precisão
- A estratégia de limpeza do cache de páginas foi aprimorada para proporcionar uma navegação mais fluida
- A experiência de conexão com o OneDrive foi aprimorada com suporte para login com conta corporativa ou escolar
