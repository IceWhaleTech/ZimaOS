## [1.7.0]

### Added
- L'App Store è stato riprogettato con una nuova interfaccia per offrire un'esperienza di navigazione delle app più moderna e chiara
- È stata aggiunta una pagina di gestione delle app per amministrare in un unico posto le app installate, lo stato degli aggiornamenti e le azioni comuni
- È stata aggiunta una pagina di scoperta delle app con raccomandazioni migliorate, navigazione per categorie e presentazione dei contenuti
- È stato aggiunto il supporto nativo per YAML per una migliore esperienza di modifica e analisi delle configurazioni

### Fixed
- Risolto il problema della sovrapposizione del conteggio dei file nella pagina di backup
- Risolti i rallentamenti durante il backup di file di grandi dimensioni

### Improved
- È stata migliorata l'esperienza visiva per gli elenchi delle app, le pagine delle categorie e le pagine di dettaglio delle app
- È stata migliorata la visualizzazione dei log dei container per una migliore leggibilità e una risoluzione dei problemi più efficiente
- Sono state migliorate le operazioni del terminale dei container con uno stato di esecuzione più chiaro e un migliore feedback interattivo
- È stata migliorata la logica di rilevamento delle licenze commerciali per una maggiore compatibilità e precisione
- È stata migliorata la strategia di pulizia della cache delle pagine per un'esperienza di navigazione più fluida
- È stata migliorata l'esperienza di connessione a OneDrive con il supporto all'accesso tramite account aziendale o scolastico
