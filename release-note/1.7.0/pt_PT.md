## [1.7.0]

### Added
- A App Store foi redesenhada com uma nova interface para proporcionar uma experiência de navegação de aplicações mais moderna e mais clara
- Foi adicionada uma página de gestão de aplicações para gerir aplicações instaladas, estado das atualizações e ações mais comuns num só local
- Foi adicionada uma página de descoberta de aplicações com recomendações melhoradas, navegação por categorias e apresentação de conteúdos
- Foi adicionado suporte nativo a YAML para uma melhor experiência de edição e análise de configurações

### Fixed
- Corrigida a sobreposição da contagem de ficheiros na página de cópia de segurança
- Corrigida a lentidão ao fazer cópias de segurança de ficheiros grandes

### Improved
- A experiência de apresentação das listas de aplicações, páginas de categorias e páginas de detalhes das aplicações foi melhorada
- A apresentação dos registos dos contentores foi melhorada para oferecer melhor legibilidade e eficiência na resolução de problemas
- As operações do terminal do contentor foram melhoradas com um estado de execução mais claro e melhor feedback interativo
- A lógica de deteção de licenças comerciais foi melhorada para oferecer melhor compatibilidade e precisão
- A estratégia de limpeza da cache das páginas foi melhorada para uma experiência de navegação mais fluida
- A experiência de ligação ao OneDrive foi melhorada com suporte para início de sessão com conta profissional ou escolar
