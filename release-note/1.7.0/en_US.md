## [1.7.0]

### Added
- Redesigned the App Store with a new UI for a more modern and clearer app browsing experience
- Added an app management page to manage installed apps, update status, and common actions in one place
- Added an app discovery page with improved app recommendations, category browsing, and content presentation
- Added native YAML support for a better configuration editing and parsing experience

### Fixed
- Fixed overlapping file counts on the backup page
- Fixed lag when backing up large files

### Improved
- Improved the display experience for app lists, category pages, and app detail pages
- Improved container log display for better readability and troubleshooting efficiency
- Improved container terminal operations with clearer execution status and interaction feedback
- Improved commercial license detection logic for better compatibility and accuracy
- Improved the page cache cleanup strategy for a smoother browsing experience
- Improved OneDrive connection experience with support for work or school account sign-in
