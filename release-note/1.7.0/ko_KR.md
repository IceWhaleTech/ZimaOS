## [1.7.0]

### Added
- 더 현대적이고 명확한 앱 탐색 경험을 위해 App Store를 새로운 UI로 개편했습니다
- 설치된 앱, 업데이트 상태, 자주 사용하는 작업을 한곳에서 관리할 수 있는 앱 관리 페이지를 추가했습니다
- 앱 추천, 카테고리 탐색, 콘텐츠 표시를 개선한 앱 탐색 페이지를 추가했습니다
- 더 나은 구성 편집 및 파싱 경험을 위해 기본 YAML 지원을 추가했습니다

### Fixed
- 백업 페이지에서 파일 수 표시가 겹치던 문제를 수정했습니다
- 대용량 파일을 백업할 때 발생하던 지연을 수정했습니다

### Improved
- 앱 목록, 카테고리 페이지, 앱 상세 페이지의 표시 경험을 개선했습니다
- 더 나은 가독성과 문제 해결 효율을 위해 컨테이너 로그 표시를 개선했습니다
- 더 명확한 실행 상태와 상호작용 피드백으로 컨테이너 터미널 작업을 개선했습니다
- 더 나은 호환성과 정확성을 위해 상용 라이선스 감지 로직을 개선했습니다
- 더 부드러운 탐색 경험을 위해 페이지 캐시 정리 전략을 개선했습니다
- 회사 또는 학교 계정 로그인을 지원하도록 OneDrive 연결 경험을 개선했습니다
