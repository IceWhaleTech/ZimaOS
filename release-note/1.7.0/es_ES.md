## [1.7.0]

### Added
- Se rediseñó la App Store con una nueva interfaz para ofrecer una experiencia de exploración de aplicaciones más moderna y clara
- Se añadió una página de gestión de aplicaciones para administrar en un solo lugar las aplicaciones instaladas, el estado de las actualizaciones y las acciones comunes
- Se añadió una página de descubrimiento de aplicaciones con mejores recomendaciones, navegación por categorías y presentación de contenido
- Se añadió compatibilidad nativa con YAML para mejorar la experiencia de edición y análisis de configuraciones

### Fixed
- Se corrigió la superposición del recuento de archivos en la página de copias de seguridad
- Se corrigió la lentitud al realizar copias de seguridad de archivos grandes

### Improved
- Se mejoró la experiencia visual de las listas de aplicaciones, las páginas de categorías y las páginas de detalles de las aplicaciones
- Se mejoró la visualización de los registros de contenedores para ofrecer una mejor legibilidad y una resolución de problemas más eficiente
- Se mejoraron las operaciones del terminal del contenedor con un estado de ejecución más claro y una mejor retroalimentación interactiva
- Se mejoró la lógica de detección de licencias comerciales para lograr una mejor compatibilidad y precisión
- Se mejoró la estrategia de limpieza de la caché de páginas para ofrecer una experiencia de navegación más fluida
- Se mejoró la experiencia de conexión de OneDrive con compatibilidad para iniciar sesión con cuentas de trabajo o escuela
