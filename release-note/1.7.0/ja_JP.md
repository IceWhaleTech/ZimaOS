## [1.7.0]

### Added
- App Store を新しい UI で刷新し、よりモダンで分かりやすいアプリ閲覧体験を実現しました
- インストール済みアプリ、更新状況、よく使う操作を 1 か所で管理できるアプリ管理ページを追加しました
- アプリのおすすめ、カテゴリ閲覧、コンテンツ表示を改善したアプリ発見ページを追加しました
- 設定の編集と解析をより快適にするため、ネイティブな YAML サポートを追加しました

### Fixed
- バックアップページでファイル数が重なって表示される問題を修正しました
- 大きなファイルをバックアップする際の遅延を修正しました

### Improved
- アプリ一覧、カテゴリページ、アプリ詳細ページの表示体験を改善しました
- 読みやすさとトラブルシューティング効率を高めるため、コンテナログの表示を改善しました
- 実行状態の表示と操作フィードバックをより明確にし、コンテナターミナル操作を改善しました
- より高い互換性と精度を実現するため、商用ライセンス検出ロジックを改善しました
- よりスムーズなブラウジング体験のため、ページキャッシュのクリーンアップ戦略を改善しました
- 職場または学校アカウントでのサインインをサポートし、OneDrive の接続体験を改善しました

### Note
- ソフトウェアの問題を見つけた場合は、Discord コミュニティに参加して、43,000 人の Zima コミュニティメンバーとつながり、サポートを受けてください
