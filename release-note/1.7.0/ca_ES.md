## [1.7.0]

### Added
- S'ha redissenyat l'App Store amb una nova interfície per oferir una experiència de navegació d'aplicacions més moderna i clara
- S'ha afegit una pàgina de gestió d'aplicacions per administrar en un sol lloc les aplicacions instal·lades, l'estat de les actualitzacions i les accions habituals
- S'ha afegit una pàgina de descoberta d'aplicacions amb recomanacions millorades, navegació per categories i una presentació del contingut més clara
- S'ha afegit compatibilitat nativa amb YAML per a una millor experiència d'edició i anàlisi de configuracions

### Fixed
- S'ha corregit la superposició del recompte de fitxers a la pàgina de còpia de seguretat
- S'ha corregit la lentitud en fer còpies de seguretat de fitxers grans

### Improved
- S'ha millorat l'experiència de visualització de les llistes d'aplicacions, les pàgines de categories i les pàgines de detall de les aplicacions
- S'ha millorat la visualització dels registres del contenidor per oferir una millor llegibilitat i més eficiència en la resolució de problemes
- S'han millorat les operacions del terminal del contenidor amb un estat d'execució més clar i una millor resposta interactiva
- S'ha millorat la lògica de detecció de llicències comercials per aconseguir una millor compatibilitat i precisió
- S'ha millorat l'estratègia de neteja de la memòria cau de pàgines per oferir una experiència de navegació més fluida
- S'ha millorat l'experiència de connexió de OneDrive amb compatibilitat per iniciar sessió amb comptes de feina o escola
